## Flappy Bird Canvas Game
**Live Demo:** [Play Game](https://nadia-dia.github.io/nadia-dia-JSFEPRESCHOOL2024Q2/random-game/)
**Technologies:** JavaScript (ES6+), HTML5 Canvas, CSS3

**Game Features:**
- Smooth 60fps animations and gameplay
- Collision detection with pipes and ground
- Score tracking system
- Spacebar controls for bird movement
- Game over animation with falling bird effect
- Sound effects for wing flaps, scoring, and collisions

**Technical Highlights:**
- HTML5 Canvas API for 2D rendering
- Procedural JavaScript with game loop architecture
- Game loop using requestAnimationFrame for smooth animation
- Custom physics simulation (gravity, acceleration, jump mechanics)
- Real-time collision detection algorithms
- Dynamic pipe generation with random positioning
- Audio integration for immersive gameplay

**Gameplay:**
- Guide the bird through pipes by pressing spacebar
- Avoid collisions with pipes and ground
- Score points for each pipe successfully passed
- Game over triggers falling animation before restart

**Controls:**
- **Spacebar** - Make the bird jump upward
